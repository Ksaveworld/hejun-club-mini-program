## 默认状态与接入条件

- 迁移只能显式运行 `initializeGrantDatabase`；两个运行入口仅验证已安装结构，不隐式升级。
- 已安装时装配消费读取及历史，启动代码仍不提供真实核验/批准来源和签名配置，赠送写入口保持关闭。关闭写不会剥夺已存在的合法赠送读取。
- 业务 resolver 必须使用服务端可靠绑定/逐人逐等级批准及同事务锁。测试的 `synthetic_grant_evidence` 仅在隔离夹具内存在，不能作为上线数据源。手机号自填或格式合法仍不足以授权。
- 本候选不注册新迁移编号、不启用短信、不修改实际客户账号。真实来源由统一集成者补齐并验收后，才讨论实际写启用。
