## API契约候选（待接口评审冻结，以下不是现有可调用端点）

沿用宿主管理路由命名，建议 `/api/admin/membership-grants` 前缀。接入者可在首次冻结时调整路径，但字段/错误含义必须同步页面契约。

| 操作 | 请求/响应最小约定 |
|---|---|
| POST `/lookup` | 输入精确标识类型和值；仅授权管理员；返回userId、脱敏身份摘要、verified状态/核验依据类型。禁止模糊姓名自动确定对象；无可靠证据返回阻断而非猜测。查询不放完整手机号进URL |
| POST `/preflight` | userId、reason、已核定批准引用；策略由服务端取。返回ready、blockers、identitySummary、existingEntitlements、proposal（level/start/expiry/timeZone/policyVersion）、confirmationToken及expiresAt；禁止客户端传approved:true获得授权 |
| POST 根路径 | userId、confirmationToken、idempotencyKey及冻结请求字段；返回grantId、实际生效区间、duplicate、来源和当前有效权益。未知结果先按键恢复查询/同键重试，不新键重发 |
| GET 根路径 | userId/status/cursor/limit；服务端设上限，返回items/nextCursor；包含可显示历史，不泄露其他账号敏感资料 |
| POST `/:grantId/revoke` | reason及必要版本/防重字段；返回原或新撤销结果、duplicate、剩余有效权益；不能通过传userId撤销错对象 |
| 既有 GET `/api/me` | 保留付费来源信息，增加effectiveEntitlements与各等级有效期限；兼容membership展示方案单列，禁止填虚假orderId |

错误沿用宿主外层封装，统一至少 `{code,message,details?,requestId?}`；禁止直接透出SQL/秘密。401未登录、403越权/运营身份、400输入错误、404对象不可用、409业务未定/权益变化/确认过期/幂等冲突，503功能关闭或迁移未就绪。候选已有 BUSINESS_DECISIONS_UNCONFIRMED、PREFLIGHT_BLOCKED、PREFLIGHT_CHANGED、IDEMPOTENCY_CONFLICT、OPERATIONAL_ACCOUNT，可复用并补全HTTP映射。失败不能显示成功，503不能自动降级为只改前端标签。
