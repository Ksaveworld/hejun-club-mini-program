# 2026-09-14 MVP阶段技术审核

基线：9ca360b951953f4cb7fd243ae92130b2507ead85。此批为开发审核版本，不是正式上线或支付验收完成版本。

## 已实现

- 六类专业服务与24个模块详情，企业名录单独页签，支持分类独立访问。
- 活动问卷采用限时弹窗和独立分段表单，供给/需求两套题目、保存回执、重复保护、后台导出；活动到期关闭入口并拒收，历史记录保留。
- 基础/星级保留销售订单，机构与专业档仅预报名；服务端拒绝第三档付款，异常到账只记录待核对。
- 有效付费会员直接发布，注册用户读取；运营下架及原因反馈，重复请求不重新发布已下架稿。
- 推荐大使申请登记、本人进度、后台跟进；不计奖、不生成提现余额。
- 独立微信支付通知验签解密模块，尚未接入HTTP入口；备份恢复摘要覆盖新增问卷与申请表。

## 建议审核重点

1. server/domain.mjs：预报名与历史会籍兼容、异常到账处理。
2. server/posts.mjs、server/ambassadors.mjs：权限、幂等、状态变化与审计。
3. server/surveys.mjs、server/campaign.mjs：字段验证、个人数据读取范围、活动有效期。
4. server/wechat-pay-verification.mjs：原始字节验签、公钥ID、时间窗口、解密及主体金额校验。
5. scripts/backup.mjs：schema 9/10新增表备份核对及旧库兼容。
6. 原生与网页入口是否一致，实际微信工具和真机需要补验。原生工程导入miniprogram目录。
